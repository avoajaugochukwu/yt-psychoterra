# Changelog — 2026-09

One month of the changelog. Index: [`../CHANGELOG.md`](../CHANGELOG.md).

## 2026-09-03

- **Per-render encoder fingerprint randomization** (`render-modal/modal_app.py`).
  Every upload used to share one identical x264 signature (libx264 / CRF 26 /
  preset medium, no container tag) — a duplicate-detection tell on YouTube. New
  `_pick_encoder(render_id)` seeds off the render id (deterministic, logged as
  `[render-enc <id>] …`, varied across videos): CRF jitters 25–27, preset picks
  from medium/faster/veryfast, and a plausible `Lavf*` `encoder` tag is stamped
  on the final mux. Also added `-movflags +faststart`. Picked once per render and
  shared by every clip, so a video stays internally consistent. Quality-safe
  bands sit next to the old baseline — the look never moves. Mirrors the
  military video-agents `pickEncoderSettings` approach. Removed the now-dead
  `PRESET` constant.
